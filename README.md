# Tile Time — JNL Studio

新版花磚時鐘產品展示網站，以用戶提供的兩張圖片製作。保留英文及 JNL Studio 名稱；Tile Time 為本次設計的系列名稱。

## 開啟
直接以瀏覽器開啟 index.html。或在本資料夾執行 `python3 -m http.server 8000`，然後開啟 http://localhost:8000。

## 架構
首頁 → 兩款產品 → 視覺細節 → 款式選擇 → FAQ → 結尾。

包含款式切換、圖片放大、資料複製（有文字備援）、原生 FAQ、鍵盤焦點樣式及減少動畫設定。無需套件或編譯。發布時上傳整個資料夾內容。
